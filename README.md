# 📊 Analisador de Ações B3

Aplicativo web para análise de ações da Bolsa Brasileira combinando indicadores fundamentalistas e técnicos.

🔗 **Acesse online:** [Seu link do Render aqui]

## ✨ Funcionalidades

- 🔍 Análise de múltiplos tickers
- 📈 Indicadores fundamentalistas: P/L, P/VP, ROE, Margens, Dívida/EBITDA
- 📉 Indicadores técnicos: RSI, Médias Móveis, Bandas de Bollinger
- 🎯 Veredito automático com preço-alvo e stop loss

## ⚠️ Aviso Legal

## 🛠️ Tecnologias

- Python 3.11
- Streamlit
- yfinance, pandas, ta

## 📡 Fontes de Dados

- Yahoo Finance (via yfinance) - Dados gratuitos com delay de ~15min
